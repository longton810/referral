# Dental Referral

Open index.html to use the form. Upload index.html, style.css, and script.js to the referral repository for GitHub Pages. No external libraries or PDF assets are required; the original form and PDF library are bundled in script.js. Keep PDF-LIB-LICENSE.md with the project.

Select one or more specialists and teeth. The downloaded PDF circles the selections on the original form. Patient is a child changes the letter to address the patient's parents. Age under 18 checks this option automatically; the checkbox can be changed. Gender Other reveals a free-text field. Dental clinic defaults to POD-2. The signature line remains blank for signing.

Preview updates automatically and can be refreshed manually. Form inputs are saved locally in this browser. They are not sent to a server.

On the PDF, gender and age appear only after the patient name: Scott Abel (M-65). Male = M, Female = F; Other uses the first letter of the entered gender, or O when empty. Date remains on its own line.
